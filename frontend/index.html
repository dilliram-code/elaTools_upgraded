Live lookup from the Materials Project (search by formula)

Uses the official, documented Materials Project REST API to fetch real DFT-computed elastic tensors for ~13,000+ materials. You need your own free API key from your Materials Project dashboard. Your key is sent directly to the Materials Project per request and is never stored by this app.

3D formulas follow the Voigt–Reuss–Hill averaging scheme; AL follows Kube (AIP Advances 6, 095209, 2016); AU follows Ranganathan & Ostoja-Starzewski (PRL 101, 055504, 2008); stability follows Mouhat & Coudert (Phys. Rev. B 90, 224104, 2014). Wave velocities and power flow angle use the Christoffel equation. This is an independent, from-scratch reimplementation inspired by the original ElATools project by Shahram Yalameha et al. — see this project's README for full validation notes.
